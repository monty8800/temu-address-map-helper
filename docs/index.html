Temu 地址地图助手Temu Address Map Helper

在 Temu 订单后台的每条订单收货地址旁注入一个「📍 地图」按钮，点击弹出中文小地图定位该地址，帮助运营人员发货时快速判断目的地与物流渠道。

📍

一键地图

每条订单收货地址旁自动出现「📍」按钮，点击即弹出小地图。

🀄

中文地名

高德中文瓦片，州/城市名以中文显示（如「波士顿」「威斯康星州」）。

🎯

自动定位

开放地理编码（Nominatim 主 / Photon 备）解析地址，红色标记定位。

🗺️

区域视图

默认定位到收货地附近，可看清所在州/区域；「全国」按钮一键看全美。

🖱️

可拖动弹窗

拖动标题栏移动，✕ / Esc / 点遮罩关闭，+/- 或滚轮缩放。

🔒

私密本地

仅本地运行，不上传订单数据；无需任何 API Key，Leaflet 已本地打包。

🌐 支持的页面匹配 *.temu.com 下所有订单 / 发货页面

订单 / 发货页面
  • agentseller-up.temu.com/mmcs/orders.orders
  • agentseller-us.temu.com/mmsos/orders.html
  • agentseller-us.temu.com/mmsos/online-shipment.html
  • 以及 *.temu.com 上展示收货地址的页面
自动识别地址格式
  • 美国：城市, 州 邮编, United States
  • 英国 / 加拿大：英式 / 加式邮编
  • 欧洲：5 位邮编（德法意西等）
  • 含街道的完整地址

🚀 安装方法Chrome / Edge 通用

  1. 1打开浏览器地址栏，进入 chrome://extensions（Edge 为 edge://extensions）。
  2. 2打开右上角开发者模式。
  3. 3点击加载已解压的扩展程序，选择包含 manifest.json 的项目文件夹。
  4. 4刷新 Temu 订单后台，每条订单收货地址旁即出现「📍 地图」按钮。
💡 也可以直接从 Releases 页 下载 zip，解压后按上述第 3 步“加载已解压的扩展程序”选择解压文件夹。

🛠️ 技术栈

纯前端扩展，无需后端。

Chrome Manifest V3Leaflet 1.9.4高德地图中文瓦片OpenStreetMap 定位Photon 兜底零 API Key

底图坐标使用高德（GCJ-02），全国 / 区域视图下与 OpenStreetMap（WGS-84）坐标差异可忽略；街道级可能略有偏移。

数据与隐私
  • 扩展仅在本地运行，不向任何服务器上传订单数据。
  • 仅在地图定位时，把该单收货地址发给开放地图服务解析坐标。
  • 不含任何统计、广告或第三方 SDK。
